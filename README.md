 CRUD de Jogos

Projeto desenvolvido em Python para praticar operações de CRUD (Create, Read, Update e Delete) utilizando SQLite como banco de dados.

 Tecnologias utilizadas

- Python
- SQLite
- SQLite3
- VS Code

 Funcionalidades

- Cadastrar jogos
- Listar jogos
- Atualizar jogos
- Excluir jogos

 Banco de dados

O projeto utiliza um banco de dados SQLite com a tabela 'jogos', contendo:

- id — identificador do jogo
- nome — nome do jogo
- categoria — categoria do jogo
- preco — preço do jogo

 Como executar

1. Tenha o Python instalado.
2. Clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute o arquivo principal:

   projeto1.py
